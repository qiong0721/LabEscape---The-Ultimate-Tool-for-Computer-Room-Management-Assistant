代码说明：
1.cpp：运行后会持续检测按键，当按下Esc时会将当前最顶层窗口加入白名单，按下Tab时，若当前最顶层窗口不在白名单中，则强制关闭，按键可在代码中自行修改
2.cpp：运行后会持续检测"jfglzsn.exe"对应的进程并强制关闭，具体名称根据学校电脑里程序名而定

使用方法：
先打开电脑里的Devc++（学校电脑里自带）,把两份代码输进去，编译运行，分别将生成的两个程序窗口和想要保护的窗口置于顶层并加入白名单，第二个程序会一直自动关闭进程，此时打开机房管理助手的界面应显示状态为关闭。注意，运行1分钟左右后，会出现蓝屏锁定，提示“进程j关闭次数过多”,此时用第一个程序按Tab即可关闭。

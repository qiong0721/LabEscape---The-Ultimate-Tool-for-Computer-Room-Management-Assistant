# LabEscape - 机房管理助手终结工具

> 一套轻量级的 Windows 工具集，用于在学校机房环境中终止机房管理助手进程，恢复用户对个人电脑的控制权。**不依赖U盘/命令行，无需联网，已在windows7虚拟机安装最新版机房管理助手的环境中实测通过**

## 项目简介

本项目包含两个独立的 C++ 程序，旨在帮助用户在学校机房中应对管理软件的过度管控：

- **1.cpp** — 通用进程终止器，支持白名单机制，可自定义保护需要运行的窗口程序
- **2.cpp** — 专用进程终止器，持续检测并终止 `jfglzsn.exe`（机房管理助手）进程

## 功能特性

### 1.cpp - 白名单进程终止器

- 实时监听键盘输入（Esc / Tab 键）
- **Esc 键**：将当前最顶层窗口的进程 ID 加入白名单，保护该程序不被终止
- **Tab 键**：终止当前最顶层窗口的进程（若该进程不在白名单中）
- 按键映射可在源码中自由修改

### 2.cpp - 专用进程终止器

- 使用 `CreateToolhelp32Snapshot` 遍历系统所有进程
- 自动查找名为 `jfglzsn.exe` 的目标进程
- 找到后立即强制终止，并输出进程 PID 供调试参考
- 持续循环运行，防止进程被自动重启

## 编译环境

- **操作系统**：Windows 7 及以上
- **编译器**：Dev-C++或其他
- **语言标准**：C++14及以上
- **依赖**：仅依赖 Windows API（`windows.h`、`tlhelp32.h`，Dev-C++中均自带），无需另外安装第三方库

## 使用方法
**须先确认实际电脑是否允许使用命令行工具，若允许，查看方法一，否则查看方法二**

### 方法一
1. 找到机房管理助手安装所在文件夹：一般可在`开始`处找到并右键选择`打开文件位置`
2. 随便选择其中一个文件，右键选择`属性`，在`目标位置`一栏可以看到程序实际位置，复制
3. 同时按下`windows+R`，或在`开始`中搜索`运行`，唤出运行界面，输入`cmd`打开命令行，输入`cd +刚刚复制的地址`，如`cd C:\q40967354\`
4. 命令行中输入`dir /a`,可以查看到文件夹中所有文件，找到其中可能为主进程的程序名称，如`main.exe`/`jfglzsn.exe`/`jfglzs.exe`，复制
5. 用 Dev-C++ 打开 `1.cpp`（无法使用U盘的可手动输入），编译运行
6. 用 Dev-C++ 打开 `2.cpp`（无法使用U盘的可手动输入），将其中的`jfglzs.exe`替换为刚刚复制的程序名称，编译运行
7. 将需要保护的窗口（如浏览器、IDE 等）置于顶层，按 **Esc** 加入白名单
8. `2.cpp` 会自动持续关闭机房管理助手进程
9. 约 1 分钟后，管理助手可能触发蓝屏锁定（提示"进程关闭次数过多"），此时利用第一个程序，按 **Tab** 键可解除锁定

### 方法二
1. 执行方法一中的前两步
2. 新建一个C++文件，输入以下代码并编译运行：
``` 
#include<windows.h>
int main()
{
    system("cd C:\\q40967354 && dir /a");
    while(1);
} 
```
注意：需将`C:\\q40967354`替换为实际地址
3. 运行后可以查看到文件夹中所有文件，找到其中可能为主进程的程序名称，如`main.exe`/`jfglzsn.exe`/`jfglzs.exe`，复制
4. 执行方法一中的5到9步


## 技术实现

| 模块 | 核心技术 |
|------|----------|
| 键盘检测 | `GetAsyncKeyState` 异步键盘状态查询 |
| 进程遍历 | `CreateToolhelp32Snapshot` + `Process32FirstW` / `Process32NextW` |
| 进程终止 | `OpenProcess(PROCESS_TERMINATE)` + `TerminateProcess` |
| 窗口识别 | `GetForegroundWindow` + `GetWindowThreadProcessId` |
